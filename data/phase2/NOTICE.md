# Source notices for Phase 2 draft data

The official CVE List repository states that its content may be searched, downloaded and used under the [CVE Program Terms of Use](https://www.cve.org/Legal/TermsOfUse). The copyright designation and license text retained in [the Phase 1 notice](../technical/NOTICE.md) and [CVE terms copy](../technical/LICENSES/CVE_TERMS.html) apply to these redistributed records; CVE is a registered trademark of The MITRE Corporation. Individual records identify their original CNAs and other sources. Each CVE record is pinned to an immutable upstream revision with its own raw SHA-256 in the collection manifest and provenance table.

The Espressif files carry `SPDX-License-Identifier: Apache-2.0 OR MIT` in their own headers. We select the MIT option and retain the [MIT license](../technical/LICENSES/MIT.txt), each source's copyright header, original source file, pinned revision and hashes. These are source-code files; this notice does not assume that unrelated documentation has the same license. Exact source lines in each draft passage are given in `provenance.csv`.

The Phase 2 benchmark is a work in progress. Contiguous hardware excerpts can omit preprocessor context outside the chunk; refer to the full retained file before judging a claim. The source rights and content must be reviewed before external redistribution beyond the project.
