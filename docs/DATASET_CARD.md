# Technical pilot dataset card

This 31-passage pilot contains 21 CVE CNA description passages and ten Espressif per-chip SoC capability excerpts, with 6 development queries (5 identifier, 1 natural) and 12 held-out test queries (10 identifier, 2 natural). Each source URL, source revision, raw file hash and extraction step is recorded in provenance.csv; rights notices and source licenses are in data/technical/NOTICE.md and LICENSES. The data are sampled from the explicit source list, not representative of the universe of technical documents. The SoC material consists of code definitions, not prose documentation.

Queries and qrels were created by the same agent who assembled the corpus, before retrieval runs. They are not independent human judgments, and query phrasing is informed by source passages. This is a severe risk of annotation and construction bias; the sample is only an end-to-end smoke-test and results must not support broad claims. Relevance evidence and explicit audited negatives are included, while remaining pairs are unjudged. Incomplete judgments limit recall estimates. The log4j cross-reference for test01 has two positive passages because it provides relevant context; most queries have a single known positive.

Documents are shared across splits by retrieval design. No exact query text or ID is shared; topics and entities are separated where practical, though the same technical families recur. An automatically computed maximum cross-split word-token Jaccard is 0.3125; this does not prove absence of semantic near duplicates. The held-out split is not used for rule design, parameter tuning or method revision after freezing. Never claim this pilot has independent human validation or paper-scale statistical power.

To rebuild: run the pinned source collector followed by build_benchmark.py; inspect rights and compare hashes to outputs/manifests/dataset_summary.json. The collector requires network access, and raw files remain in ignored cache. If upstream immutable sources disappear or content hashes disagree, stop rather than silently changing the dataset.
