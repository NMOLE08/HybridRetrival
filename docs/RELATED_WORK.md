# Related work

1. Nils Reimers and Iryna Gurevych, “Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks,” 2019, DOI [10.18653/v1/D19-1410](https://doi.org/10.18653/v1/D19-1410), [ACL](https://aclanthology.org/D19-1410/). Sentence-BERT produces sentence embeddings suitable for cosine similarity. This project uses the established sentence-transformers infrastructure and pretrained weights, not a new trained encoder.
2. Gordon V. Cormack, Charles L. A. Clarke, and Stefan Buettcher, “Reciprocal rank fusion outperforms Condorcet and individual rank learning methods,” 2009, DOI [10.1145/1571941.1572114](https://doi.org/10.1145/1571941.1572114). RRF combines ranked lists using reciprocal ranks. It is the unmodified hybrid comparison here, not a proposed contribution.
3. Nandan Thakur, Nils Reimers, Andreas Rücklé, Abhishek Srivastava, and Iryna Gurevych, “BEIR: A Heterogenous Benchmark for Zero-shot Evaluation of Information Retrieval Models,” 2021, [NeurIPS](https://datasets-benchmarks-proceedings.neurips.cc/paper_files/paper/2021/file/65b9eea6e1cc6bb9f0cd2a47751a186f-Paper-round2.pdf), [OpenReview](https://openreview.net/forum?id=wCu6T5xFjeJ); DOI not listed by the conference record. BEIR emphasizes heterogeneous zero-shot retrieval evaluation. SciFact, if available, is only an out-of-domain robustness check, not an identifier benchmark.
4. Yi Luan, Jacob Eisenstein, Kristina Toutanova, and Michael Collins, “Sparse, Dense, and Attentional Representations for Text Retrieval,” 2021, DOI [10.1162/tacl_a_00369](https://doi.org/10.1162/tacl_a_00369), [ACL](https://aclanthology.org/2021.tacl-1.20/). This work studies sparse, dense and hybrid retrieval and limitations of fixed-dimensional encodings. It establishes that hybrid retrieval is prior art, whereas this study tests a specific lightweight post-fusion adjustment.
5. Luyu Gao, Zhuyun Dai, and Jamie Callan, “COIL: Revisit Exact Lexical Match in Information Retrieval with Contextualized Inverted List,” 2021, [ACL](https://aclanthology.org/2021.naacl-main.241/), DOI [10.18653/v1/2021.naacl-main.241](https://doi.org/10.18653/v1/2021.naacl-main.241). COIL combines contextual token representations with exact lexical matching. Its learned retrieval architecture differs from the narrowly defined, training-free identifier adjustment studied here.
6. Christopher Sciavolino, Zexuan Zhong, Jinhyuk Lee, and Danqi Chen, “Simple Entity-Centric Questions Challenge Dense Retrievers,” 2021, [arXiv:2109.08535](https://arxiv.org/abs/2109.08535); DOI not asserted. It reports difficulties of dense retrieval on entity-centric questions. Entity names are not equivalent to technical version identifiers, but the overlap cautions against claiming exact-entity handling as novel.
7. Georgios Sidiropoulos, Nikos Voskarides, Svitlana Vakulenko, and Evangelos Kanoulas, “Combining Lexical and Dense Retrieval for Computationally Efficient Multi-hop Question Answering,” 2021, DOI [10.18653/v1/2021.sustainlp-1.7](https://doi.org/10.18653/v1/2021.sustainlp-1.7), [ACL](https://aclanthology.org/2021.sustainlp-1.7/). The paper combines lexical and dense retrieval for multi-hop QA under resource constraints. It is further evidence that the combination itself is established and distinct from this identifier-specific evaluation.
8. David Wadden, Shanchuan Lin, Kyle Lo, Lucy Lu Wang, Madeleine van Zuylen, Arman Cohan, and Hannaneh Hajishirzi, “Fact or Fiction: Verifying Scientific Claims,” 2020, DOI [10.18653/v1/2020.emnlp-main.609](https://doi.org/10.18653/v1/2020.emnlp-main.609/), [ACL Anthology](https://aclanthology.org/2020.emnlp-main.609/). SciFact is a scientific claim-verification dataset and is not a direct technical-identifier benchmark.

This preliminary search does not establish novelty; further targeted literature review is required before any publication claim.
