# Independent annotation instructions

**Stage 14B:** Use the versioned [v2 workbook and instructions](PHASE2_REVIEW_V2_INSTRUCTIONS.md) for new review. The original v1 CSVs described below remain archived for provenance and should not be completed in place. All v2 judgments remain blank; the AI pre-review is separate and is not independent human annotation.

Use an independent human reviewer who did not author the questions or proposed candidates. The current package is an initial source-evidence review, not a retrieval pool; no system rankings or method names are present. Save completed copies rather than editing the archived original package.

1. Open [question_review.csv](../data/phase2/review/question_review.csv). Review each draft question for a clear, factually valid information need. Fill `reviewer_id` (a consistent real identity or pseudonym), `independent_of_author`, `reviewed_at_utc`, and `question_valid`; record any needed rewrite and reason. Agent-authored status must remain truthful. In particular, rewrite or replace development questions `esp-01` and `esp-02`, which resemble Phase 1 test queries; do not choose replacements based on retrieval performance.
2. Open [candidate_pairs.csv](../data/phase2/review/candidate_pairs.csv). For every pair, inspect the full passage and the source URL; use the source revision and retained `source_raw_path` for surrounding context, particularly around hardware preprocessor directives. The column `proposed_relevance` is `unjudged` for every row and is not a ground-truth label. Do not use document-title similarity as the sole relevance criterion.
3. Fill `human_relevance` with `1` only if the passage directly answers the stated need, `0` only if you have independently checked that it does not, or `unknown` if evidence is insufficient or ambiguous. Add your reviewer ID, independence, UTC review timestamp, confidence and source-specific reason. A document can be relevant when it explicitly discusses the requested CVE in a cross-reference even if its title names another CVE. An absent macro or an unjudged conflict is not evidence of a negative answer.
4. Check all current candidate pairs, especially all potential test positives and confusable variants. For `esp-08`, `esp-11`, and `esp-13`, no expected macro was found in the target header: check the full source and find a separately licensed reliable source or mark the need unsupported/unknown. Record any question or pair that cannot be judged. Do not force a negative. Review the two flagged cross-reference cases and add missing relevant references if evidence supports them.
5. Return the completed copies and the reviewer provenance. If possible, a second independent reviewer should label at least 20% of the pairs; record the real overlap, disagreements and adjudication, leaving unresolved cases unknown. No agreement score is available until this happens.

After the initial review, query corrections, source coverage and topic overlap must be resolved and the dataset locked. Development-only pooling and review then precede weight selection. The final test candidate pool is made only after weights are frozen, without method labels, and requires a separate independent review of pooled likely top conflicting results and positives. A CSV with blanks filled by an automated system does not qualify as independent human review. Never submit a final test metric until every test query has an audited positive and review coverage is reported.
