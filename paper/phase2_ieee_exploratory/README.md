# Phase 2 IEEE-style exploratory paper

The main TeX source uses the standard IEEEtran conference class and cites only
the works listed in the retained related-work record. Figures are referenced
from the reproducible Stage 18 output directory and are generated by
scripts/make_phase2_exploratory_artifacts.py.

Compile from this directory with an IEEEtran-enabled TeX installation, for
example by running pdflatex twice on main.tex.

The built-in desktop compiler was invoked on 2026-10-21 but could not spawn
Tectonic because the Windows sandbox returned access denied before source
processing. The repository therefore preserves the source and compiler
diagnostic, rather than claiming a generated PDF.
